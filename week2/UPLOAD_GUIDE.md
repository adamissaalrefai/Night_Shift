# Upload Guide — Nader Week 2

1. Download and extract `Week2_Nader_Upload_Package.zip`.
2. Open `https://github.com/adamissaalrefai/Night_Shift/tree/Nader`.
3. Upload the files while preserving the `week2/`, `ai-requests/`, and `ai-outputs/` paths.
4. For the two existing Week 2 files, upload the updated versions from this package:
   - `week2/W2_nader_network-analysis_v1.md`
   - `week2/W2_nader_local-llm-run-sheet_v1.md`
5. Add the new evaluation, CSV validation log, task tracker, request, and output files.
6. Use this commit message:

   `week2: add Nader network analysis and local LLM evaluation`

7. Commit directly to the `Nader` branch only. Do not touch `main`.

The original evidence files are already referenced on `week1/mahmoud-benchmark`; do not duplicate or modify them as part of this upload.
